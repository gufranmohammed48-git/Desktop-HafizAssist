01 Executive Overview & Dual User Modes

The Dawah Bot is designed as a dual-purpose AI system that operates both as an educational apologist engine for non-Muslims seeking answers about Islam, and as an interactive training simulator for Muslims learning how to give Dawah effectively.


🤝 1. Seeker Mode (Non-Muslim Q&A)

  • Respectfully answers queries on Islam, Trinity, Prophet Muhammad (pbuh), science in Quran, Sharia, and comparative theology.
  • Provides direct links to YouTube debate clips starting at the exact minute/second timestamp.
  • Includes authentic Quranic verse numbers (with Arabic & Tafsir) and Hadith references.

🎓 2. Dawah Simulator (Muslim Training Mode)

  • Interactive roleplay where the AI simulates a skeptic, Christian apologist, or atheist.
  • Allows Muslims to practice debate rebuttals and gentle presentation of Islamic arguments (*Hikmah*).
  • Evaluates user responses in real-time and provides feedback on tone, logic, and missing evidence.

02 RAG vs. Fine-Tuned "Whole Model" (The Technical Truth)

A common misconception is that fine-tuning an open-source model (using tools like Soup CLI / trysoup.dev) can replace a RAG (Retrieval-Augmented Generation) system. Here is why a Hybrid Architecture is mandatory for this project:

Capability Fine-Tuned Model Alone RAG System Alone Recommended: Hybrid System
YouTube Video & Timestamp Linking Fails (Hallucinates URLs) Passes (Exact DB Lookup) Passes (Dynamic Linking)
Hadith & Quran Citations Risk of Wrong Numbers 100% Verified Text Exact Text + Tafsir
Tone & Dawah Etiquette (Hikmah) Learned via Fine-tuning Needs System Prompt Optimal Behavior
Updating New Debate Videos Requires Re-training Instant Indexing Instant Ingestion
Key takeaway: The LLM provides the intelligence and eloquence, while the RAG database provides the factual accuracy, exact timestamps, and authentic text references.

from youtube_transcript_api import YouTubeTranscriptApi

def fetch_timestamped_transcript(video_id):
    transcript = YouTubeTranscriptApi.get_transcript(video_id)
    # Returns array of: {'text': '...', 'start': 452.3, 'duration': 4.1}
    return transcript

# 2. Dynamic URL Generator
def build_youtube_link(video_id, start_seconds):
