# Direct Execution Guidelines

- **Immediate Action**: When the user requests code edits, refactoring, or file creation, execute the changes directly using the code edit tools.
- **No Confirmation Prompts**: Do NOT stop to ask questions like "Would you like me to make these changes?" or wait for manual confirmation before editing files.
- **Auto-Implement**: Proceed directly to writing the code, updating files, and verifying the result.
