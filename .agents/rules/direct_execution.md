# Direct Execution & No Permission Prompts Rule

- **Do Not Ask for Permissions**: If you are making any change, go ahead and do it directly. Do NOT ask for permission, approval, confirmation, or review before making code changes or running verification commands unless the user specifically mentions to ask.
- **Immediate Execution**: When the user requests code edits, bug fixes, refactoring, or file creation, execute the changes immediately without hesitation.
- **Proactive Implementation**: Edit the files, sync parity across files (e.g. index.html, mobile.html, test.html), verify correctness, and present the final result directly.
